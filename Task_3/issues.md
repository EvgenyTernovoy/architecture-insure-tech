## Риски текущей архитектуры при росте числа партнеров

1. Синхронная цепочка запросов
   - один недоступный партнер блокирует всю цепочку запросов
   - при увеличении числа страховых компаний время отклика и вероятность таймаута растут линейно
2. Отсутствие кэширования
   - если данные о продуктах редко меняются, каждый раз заново собираем информацию
   - избыточную нагрузку и на aggregator, и на API страховых компаний
3. Несогласованность данных между сервисами
4. Тесная связанность по API
   - любая недоступность одного сервиса может привести к недоступности других сервисов
