## Анализ REST API контракта

**Ключевые ресурсы:**

- Client - основная сущность
- Document - принадлежат клиенту
- Relative - связаны с клиентом
- 
**Операции REST API:**

- GET /clients/{id} - получение данных клиента
- GET /clients/{id}/documents - получение документов клиента
- GET /clients/{id}/relatives - получение родственников клиента

**Проблемы REST подхода:**

- для получения полной информации о клиенте с документами и родственниками нужно делать 3 запроса
- всегда получаются все поля сущности, даже если нужны только некоторые
- нельзя получить клиента с документами в одном запросе
